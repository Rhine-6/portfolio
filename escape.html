案例 01 · 碎片拾取系统

距离检测与拾取反馈

碎片需要在近距离按 E 交互，随后移动到配置的目标位置并更新收集数量。

  1. 01
    交互异常

    开发记录称，按 E 没有产生预期拾取反馈。

  2. 02
    测试与调整

    记录提到交互距离与角度经过多轮调整；具体参数和旧版代码未留存。

  3. 03
    当前实现

    当前脚本按相机与物体的距离判断，按 E 后立即计数并启动目标位移。

源码没有朝向角度筛选或多个目标互斥；多个近距离碎片可能响应同一次 E 输入。

  • E 键交互
  • 距离检测
  • Target 位移
  • 收集计数

MainMenu.cs开始游戏回调
void OnStartGame()
{
    Debug.Log("点击了开始游戏");
    gameObject.SetActive(false);
    foreach (GameObject go in Resources.FindObjectsOfTypeAll<GameObject>())
    {
        GameInit init = go.GetComponent<GameInit>();
        if (init != null)
        {
            init.StartGame();
            break;
        }
    }
}
GameInit.csstarted 门控
if (!started) return;

if (!initialized)
{
    fadePanel = FindByName("FadePanel");
    tipPanel = FindByName("TipPanel");

    if (fadePanel != null && tipPanel != null)
    {
        initialized = true;
        Init();
    }
    return;
}
